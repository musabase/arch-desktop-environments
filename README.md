# Arch Desktop Environments

Setup notes for choosing and installing a desktop environment on Arch Linux. A fresh Arch install boots to a terminal, this covers the three most common graphical options.

- [KDE Plasma](kde-plasma.md)
- [GNOME](gnome.md)
- [XFCE](xfce.md)

Each file links to a full step-by-step installation guide on [MusaBase](https://www.musabase.com).
